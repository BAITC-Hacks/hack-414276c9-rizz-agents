# Аким на 5 часов

Локальный веб-симулятор задачи Astana Innovations: разложить одинаковый для всех команд виртуальный бюджет по транспорту, озеленению, социальной сфере, безопасности и городским сервисам. Пользователь принимает ровно пять решений и сразу видит последствия для Astana Quality of Life Score.

## Что умеет приложение

- Даёт выбрать ровно пять городских мер на общий бюджет в 100 условных единиц.
- Проверяет ограничения датасета: бюджет, число мер по направлениям, районные назначения и несовместимые меры.
- Рассчитывает влияние мер с учётом задержки реализации и синергий, обновляет оценки районов и Astana Quality of Life Score.
- Показывает изменения по районам и предлагает сценарий, нацеленный на слабые показатели Нуры.
- AI-агент объясняет рассчитанные результаты и компромиссы. Расчёт чисел выполняет код симулятора, а языковая модель только объясняет их.

Все показатели районов синтетические и используются для демонстрации модели.

## Запуск в VS Code на Windows

1. Установите Node.js версии 20 или новее, если он ещё не установлен.
2. Откройте в VS Code папку `hack-414276c9-rizz-agents`.
3. Откройте меню **Terminal → New Terminal**.
4. Запустите приложение:

   ```powershell
   npm start
   ```

5. Откройте в браузере [http://localhost:3000](http://localhost:3000).
6. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Пакеты устанавливать не требуется: сервер использует встроенные возможности Node.js.

## Подключение AI-пояснения

Без API-ключа симулятор работает с локальным пояснением. Чтобы включить ответы модели, скопируйте `.env.example` в `.env` и добавьте ключ после `OPENAI_API_KEY=`:

```powershell
Copy-Item .env.example .env
notepad .env
npm start
```

Если сервер уже запущен, остановите его `Ctrl+C` и запустите заново после сохранения `.env`. При старте в терминале появится сообщение, найден ли ключ; сам ключ не выводится. При необходимости можно выбрать модель через `OPENAI_MODEL` в `.env`. Ключ остаётся на сервере и не передаётся браузеру. Файл `.env` добавлен в `.gitignore`: не публикуйте его и не вставляйте ключ в файлы интерфейса. Использование OpenAI API может тарифицироваться отдельно.

## Основной сценарий

1. Нажмите **Предложить план для Нуры**, чтобы загрузить готовый допустимый набор из пяти мер.
2. Посмотрите затраты и сравните баллы районов.
3. Нажмите **Объяснить результат**, чтобы получить AI-анализ или локальное пояснение.
4. Удалите меру, выберите другую в каталоге и нажмите **Рассчитать сценарий** для сравнения.

## Структура проекта

- `server.mjs` — локальный веб-сервер и серверный вызов OpenAI API.
- `src/data.mjs` — показатели районов, веса, каталог мер и бюджет.
- `src/simulator.mjs` — валидация выбора и расчёт результата.
- `public/` — страница симулятора, интерфейс и браузерная логика.

## Ограничения модели

- Районы, показатели и эффекты мер являются синтетическими.
- Горизонт расчёта — 8 условных кварталов; задержки учитываются как доля полного эффекта.
- Остаток бюджета не сгорает и не добавляет баллы.
- Рекомендованный сценарий — демонстрационный вариант для Нуры, а не оптимальное решение для реального города.
- AI-пояснение зависит от доступности API и не меняет рассчитанные показатели.
