# Аким на 5 часов

Локальный симулятор для задачи Astana Innovations. Команда распределяет одинаковый виртуальный бюджет по городским направлениям, выбирает пять мер и видит, как они могут повлиять на Astana Quality of Life Score и каждый из пяти районов.

## Возможности

- Каталог мер сгруппирован по направлениям: транспорт, озеленение, соцсфера, безопасность и городские сервисы.
- Можно собрать собственный набор или автоматически подобрать сбалансированный план для города либо отдельного района.
- Перед расчётом проверяются бюджет, число мер по категориям, обязательный выбор района и несовместимые решения.
- Результаты показывают общий балл города и изменение балла каждого района.
- AI-аналитик объясняет пользу, риски и следующий шаг. Если API недоступно, используется локальное пояснение. AI не рассчитывает и не меняет числа.
- Дополнительный AI-штаб сопоставляет план с пятью городскими стресс-сценариями: воздух, пробки, школы, пожары в жилом секторе и теплосети. Проверка добровольная и не меняет Score, бюджет или выбранные меры.

Все показатели и эффекты мер синтетические и служат демонстрацией модели. Городские проблемы показываются как контекст из датированных источников, а не как оперативные данные. Районные баллы нельзя трактовать как реальные оценки районов.

## Запуск в VS Code на Windows

1. Установите Node.js версии 20 или новее.
2. Откройте в VS Code папку проекта `hack-414276c9-rizz-agents`.
3. Откройте **Terminal → New Terminal** и выполните:

   ```powershell
   npm start
   ```

4. Не закрывая терминал, откройте в браузере [http://localhost:3000](http://localhost:3000).
5. Остановка: нажмите `Ctrl+C` в терминале, где запущен сервер.

Устанавливать дополнительные пакеты не нужно.

> `localhost` — это адрес вашего компьютера. Ссылка откроется только на том же компьютере, где запущена команда `npm start`. Если видите `ERR_CONNECTION_REFUSED`, сервер не запущен или уже остановлен: вернитесь в папку проекта, снова выполните `npm start` и оставьте терминал открытым. Чтобы сайт открывался у других людей по ссылке из README, его нужно сначала опубликовать на хостинге и заменить `localhost` на адрес опубликованного сайта.

## Публикация для жюри

Проект подготовлен для Render: файл `render.yaml` задаёт настройки публичного веб-сервиса, а сервер принимает подключения извне.

1. Отправьте актуальную версию проекта в GitHub.
2. Войдите на [Render](https://render.com/), выберите **New → Blueprint** и подключите репозиторий `BAITC-Hacks/hack-414276c9-rizz-agents`.
3. Подтвердите создание сервиса по настройкам из `render.yaml` и дождитесь статуса **Live**.
4. Скопируйте выданный Render адрес вида `https://имя-сервиса.onrender.com` и отправьте его жюри. Этот адрес открывается с других устройств.

На бесплатном тарифе Render может усыплять сервис после периода без запросов, поэтому первое открытие после паузы может занять около минуты. Если для AI-пояснений нужен OpenAI, задайте `OPENAI_API_KEY` в **Environment** сервиса Render; без ключа сайт продолжит работать с локальным пояснением.

## Как пользоваться

1. Нажмите **Подобрать план** и выберите город или нужный район либо соберите свой набор вручную.
2. При ручном выборе отфильтруйте каталог по направлениям, выберите меры и укажите район для районных проектов.
3. Убедитесь, что выбрано ровно пять мер и расходы не превышают 100 условных единиц.
4. Нажмите **Рассчитать сценарий** и сравните общий балл с результатами районов.
5. Нажмите **Объяснить результат**, чтобы получить краткий разбор пользы, рисков и следующего шага.
6. При желании нажмите **Проверить план на кризисы**. Откройте карточки, чтобы увидеть, какие меры связаны с каждым риском, их эффекты и задержки в симуляции, ограничения модели и варианты для сравнения.

## AI-пояснение

Без API-ключа симулятор использует автоматическое локальное пояснение. Чтобы включить AI, скопируйте `.env.example` в `.env` и добавьте ключ после `OPENAI_API_KEY=`:

```powershell
Copy-Item .env.example .env
notepad .env
npm start
```

Если сервер уже работает, остановите его через `Ctrl+C` и запустите снова. Сервер сообщает, найден ли ключ, но не печатает его. Файл `.env` исключён из Git; не добавляйте секрет в браузерный код или опубликованные файлы. Запросы к OpenAI API могут тарифицироваться отдельно.

## Расчёт и ограничения

- Меры изменяют синтетические показатели районов. Для задержки запуска применяется доля эффекта в горизонте восьми условных кварталов.
- Городские меры влияют на все районы; районные — только на выбранный район.
- Astana Quality of Life Score складывается из 70% среднего результата с учётом населения, 30% результата самого слабого района и штрафа за каждый показатель ниже 40. Промежуточные значения не округляются; итог отображается с двумя знаками.
- Рекомендации перебирают допустимые комбинации пяти мер по встроенному набору данных. Городской вариант максимизирует общий балл, районный — улучшение выбранного района с учётом общего результата города.
- Расходы являются условными, а оценки не являются прогнозом фактических последствий или финансовой сметой.

## Структура

- `server.mjs` — локальный сервер и вызов OpenAI API.
- `src/data.mjs` — районы, исходные показатели и меры.
- `src/simulator.mjs` — проверка сценариев, расчёт баллов и подбор рекомендаций.
- `public/` — интерфейс и браузерная логика.
